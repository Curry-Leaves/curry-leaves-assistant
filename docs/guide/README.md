# Curry Leaves — User Guide

The end-user manual is a single, self-contained web page.

**Read it online: → [ilayanambi.com/curryleaves](https://ilayanambi.com/curryleaves)**

The source lives here at **[`site/index.html`](site/index.html)** — open it in a browser or serve
`site/` statically. It's the one source of truth for how to use Curry Leaves — getting started,
every screen, an FAQ, and a tour of what changes in your day. Light/dark themes, a section index,
and per-section keywords are built in.

Screenshots and GIFs it references live in [`site/assets/`](site/assets/).

For how the app is *built* (not used), see [`../architecture.md`](../architecture.md) and the
[design docs](../README.md).
