This is a one-on-one. Keep it personal and candid; these notes are usually private to the
two people involved.

**Discussion** — the main threads: how things are going, blockers, feedback in both
directions, anything personal worth remembering. Bullets, grouped by topic.

**Follow-ups** — concrete things either person agreed to do. Name the owner. Create a todo
for each; don't invent deadlines the conversation didn't set.

**For next time** — open threads to pick back up in the next 1:1 so nothing quietly drops.
Include unresolved questions and anything explicitly deferred.
